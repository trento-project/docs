[[sec-trento-settings-webconsole]]
=== Configuring {tr_web} settings
:revdate: 2026-11-19

Users with the `all:settings` permission can use the *Settings* view of {tr_web} to modify the following:

* API key. See <<sec-trento-rotating-apikeys>>.
* Connection data for SUSE Multi-Linux Manager. See <<sec-integration-with-suse-multi-linux-manager>>.
* Retention time for Activity Log entries. See <<sec-activity-log-retention>>.
* Settings required for sending alerts via email. See <<sec-enabling-email-alerts>>.
+
If any of the email settings are specified through environment variables, the
web-based email configuration is disabled.
