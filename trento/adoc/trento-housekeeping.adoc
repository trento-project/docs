[[sec-housekeeping]]
=== Cleaning up hosts and instances
:revdate: 2026-11-27

Housekeeping removes hosts that stop reporting and instances that {trento} no longer discovers from the {tr_web} console. Because these components otherwise remain visible with their last known data, the *Clean up* button appears in the console so you can prevent clutter and keep your overviews accurate. 

Performing housekeeping actions requires the `cleanup:all` permission.

. In the {tr_web} console, open the overview or details view of the affected host, {sap} system or {hana} database.
. To remove the host or instance and all dependent components, click the *Clean up* button.
+
[NOTE]
====
Cleaning up a host removes the host, all components discovered on it and their dependent components from the {tr_web} console. Cleaning up an instance removes the instance and its dependent components. For example, an entire {sap} system is removed if you clean up its ASCS instance or the host with its registered primary application server.
====
