== Administration and personal settings

{trento} administration and personal settings keep your monitoring environment secure and efficient. Administrators can control access and optimize server performance through ongoing tasks such as managing permissions or adjusting storage. Individual users can customize their account preferences, including authentication options and API access, without requiring administrative permissions.
