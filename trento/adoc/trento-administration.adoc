== Administration and personal settings

{trento} administration and personal settings keep your monitoring environment secure, organized and efficient. Administrators can control access, optimize server performance and maintain system health through ongoing tasks such as managing permissions or adjusting storage. Individual users can customize their account preferences, including authentication options and API access, without requiring administrative permissions.
